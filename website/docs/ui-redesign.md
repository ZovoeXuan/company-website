# 官网视觉与媒体能力说明（对齐参考视频）

目标：按参考视频（G7 易流官网录屏，960×608，284 秒）重做官网视觉——**深黑首屏、紫色品牌强调、大字号编辑式排版**，并补齐视频素材能力，让首屏与内容主图可以直接播放视频。只改视觉与媒体链路，不动内容模型、路由与接口契约。

## 一、从参考视频归纳的特征

1. **首屏**：整幅画面（图片或视频）铺满，压暗后白字；产品名用紫色强调，标题 3 行左右，底部一条细线切换 01/02。
2. **导航**：贴近页面顶部，白底或深色一体，滚动后收缩并出现分隔线；右侧是高亮胶囊 CTA。
3. **指标区**：无卡片、无阴影，四列大数字（40px 以上）+ 细线分隔。
4. **内容区**：左右交错的产品区块，编号小标签 + 大标题 + 条目列表 + 胶囊按钮；区块间用浅雾底色分段。
5. **案例卡**：行业标签 + 客户名 + 结果数字（32% / 1.8x），图片大圆角。
6. **客户 Logo**：无边框网格，灰度显示，悬停还原。
7. **新闻**：细线分隔的列表，日期 + 标题 + 摘要 + 箭头。
8. **收尾**：深色 CTA 大标题，深色页脚，页脚电话字号大。

## 四、交互动效

- **页面转场**：`SiteLayout` 用 `<Transition name="page" mode="out-in">`，路由切换淡入 + 轻位移，`prefers-reduced-motion` 下自动关闭。
- **滚动入场**：`v-reveal` 指令（`web/src/directives/reveal.ts`）基于 IntersectionObserver，元素进入视口后加 `.is-revealed`，可选延迟；只触发一次，避免反复抖动。
- **首屏切换**：`01/02` 切换条，`heroIndex` 控制文案与媒体，`pad()` 输出两位编号。
- **视频首屏**：`<video autoplay muted loop playsinline>`，无控件、不发声，移动端同样可播放；后台可为首屏的桌面/手机分别配置图片或视频。
- **微交互**：链接箭头位移、卡片图片轻放大、按钮 hover 变色、导航下划线与 mega menu 淡入。

## 五、视频素材能力

1. **迁移** `V3__media_video.sql`：`cms_media` 增加 `media_type`（IMAGE/VIDEO）与 `duration_ms`；视频上限 50MB、允许 0×0 像素。
2. **识别**：`VideoInspector` 按文件头判断 MP4（`ftyp`）与 WebM（`0x1A45DFA3`），不信任扩展名。
3. **上传**：后台 `accept` 含 `mp4/webm`，列表支持「全部 / 图片 / 视频」筛选，视频显示首帧与时长。
4. **播放**：公开接口 `/api/public/media/{id}` 支持 Range，返回 `206` 与 `Content-Range`，拖动进度条可用；单段最多 8MB，其余流式输出。
5. **门禁**：公开读取仍要求素材被「已发布内容 / 已发布配置」引用；草稿引用返回 404。
6. **配置**：首页首屏、产品/方案/案例/新闻主图均可选视频；后台首页管理显示「桌面媒体（图片或视频）」「手机媒体」。

## 六、验证结果

- **构建**：server `mvnw -DskipTests package`、web 与 admin `npm run build` 全部通过。
- **视频链路**：上传 28MB MP4 → 后台列表识别为视频 → 首页首屏自动播放（`muted`、`readyState=4`、`currentTime > 1s`）；`Range: bytes=0-1023` 返回 `206`，完整请求返回 `200` 与正确字节数。
- **响应式**：1440 与 390 两个视口 `scrollWidth` 等于视口宽；移动端首屏、指标两列、产品区块、案例、Logo 墙、新闻、CTA 与页脚逐段截图核对，无溢出与错位。
- **控制台**：首页与后台页面无报错。

## 七、边界与待办

- **演示素材**：首屏图/循环视频、内容封面与客户 Logo 均为按参考风格生成的演示素材，上线前必须替换为真实照片、视频与已授权 Logo。
- **首个循环视频**由首屏图经 `zoompan` 生成（371KB，6 秒），仅用于演示视频链路，不是实拍素材。
- **移动端流量**：首屏视频在移动端也会加载；如需省流量，可在后台只给手机端配置图片。
- **后台**：已同步紫色主色、圆角与字体，但仍是 Element Plus 结构，不做官网级视觉重排。
- **首页首屏切换未自动轮播**：仅手动 `01/02` 切换，避免自动播放打断阅读。
