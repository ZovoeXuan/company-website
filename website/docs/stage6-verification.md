# 阶段 6 验证记录：咨询闭环

结论：**通过**（真实 MySQL 8.4.13 + 真实浏览器）。官网表单可提交到 `POST /api/public/leads`，
后台可按状态处理线索；手机号加密存储，幂等、限流、权限与审计均有实测记录。

## 1. 实现范围

| 项 | 内容 |
|---|---|
| 公开表单 | 姓名、手机号、公司、需求、来源路径、来源位置、隐私同意与版本；来源位置按白名单校验 |
| 来源关联 | `contentType` / `contentId` 成对填写，仅允许已发布的产品、方案、案例，只作来源线索 |
| 幂等 | `Idempotency-Key` 必填 UUID；同键同载荷返回原回执，同键异载荷返回 409 |
| 隐私同意 | `consentVersion` 必须等于当前已发布隐私说明版本，失效时提示重新阅读 |
| 敏感字段 | 手机号 AES-256-GCM 认证加密（版本 + nonce + ciphertext/tag），列表只显示末四位 |
| 摘要 | 幂等载荷 HMAC-SHA256（版本 1）；限流键使用 HMAC 摘要，不保存原始 IP 或手机号哈希 |
| 限流 | 同 IP 每分钟 3 次新提交、同手机号 10 分钟 3 次、通用请求 20 次/分钟；429 带 `Retry-After` |
| 表单开关 | CONTACT 未发布或 `formEnabled=false` 时返回 503 `FORM_UNAVAILABLE`；旧成功重试不受影响 |
| 后台 | 仅 ADMIN：列表（状态/日期/关键字筛选、脱敏手机）、详情（解密手机并写审计）、状态流转 |
| 状态流转 | NEW → CONTACTED/INVALID；CONTACTED → CLOSED/INVALID；CLOSED/INVALID → CONTACTED 必须填写原因 |
| 工作台 | 显示待处理咨询数；编辑角色不返回该字段，也无法读取线索接口 |
| 官网接入 | 联系页内嵌表单；首页首屏/底部、导航、页脚、详情页咨询按钮统一打开咨询弹窗并带来源位置 |

## 4. 本轮修复的问题

1. **可选字段被当成必填**：`contentType` 为空时错误地要求「请填写关联类型」。改为可选字段单独校验。
2. **表单关闭时站点配置 500**：导航项解析 CONSULT 返回 null 后仍直接读取 `action.type`。已做空值保护，`formEnabled=false` 时公开配置正常返回。
3. **并发幂等返回 409**：提交方法包在事务里时，MySQL REPEATABLE READ 快照导致冲突后回读看不到对方已提交记录。公开提交改为不包事务（单条 INSERT 原子），并发测试两次均返回同一回执。

## 6. 已知项

- 首版不接短信、邮件、导出、CRM 或线索删除按钮。
- 限流为进程内滑动窗口，单实例部署成立；多实例需改为共享存储。
- 生产环境必须配置 `CMS_LEAD_ENCRYPTION_KEY` 与 `CMS_LEAD_HASH_KEY`（各 32 字节 Base64），密钥丢失将无法解密历史手机号。
- 部署在 Nginx 后时需确认来源地址传递方式，避免所有访客共用代理 IP 触发限流。
- 线索保留周期与到期清理方式仍待公司负责人在上线清单中确认。
