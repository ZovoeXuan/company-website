## 4. 本轮修复的问题

1. **内容选择器查不到数据**：`listContents` 传 `pageSize=100`，后端上限是 50，接口 400 被前端 catch 成空列表，界面显示「没有可选的已发布内容」。改为 50。
2. **已选内容显示为 `#1`**：`ContentPicker` 只在打开弹窗时加载标题。改为挂载与值变化时补全标题缓存。
3. **内容下拉显示原始 ID**：草稿里 `contentId` 是数字，选项 value 是字符串，`el-select` 匹配失败。统一转字符串。
4. **导航父节点输出 `path: null`**：前端按 `string` 处理会渲染异常，改为空字符串，并据此判断父节点是否需要隐藏。
5. **清洗后残留空 `<img>`**：只有 `onerror` 的图片被移除属性后仍保留标签，导致读屏与审计读到无 alt 图片。清洗器现在会删除无有效 `src` 的图片。
6. **联系方式出现两处来源**：SITE 与 CONTACT 都存电话会造成不一致。按文档 6.2 收敛到 CONTACT，公开接口对旧快照做回退读取。

## 5. 未完成与已知项

- **CONSULT 动作**：表单未上线前统一跳到 `/contact`，尚未实现站内弹窗。阶段 6 接入提交接口时一并处理。
- **纯 SPA 的 SEO 时序**：详情页数据异步加载，抓取工具在数据返回前读取会看到空 `h1`。已在计划中列为预渲染待决项，本轮未处理。
- **新闻/案例/客户标识无真实数据**：首页对应区块按规则整块隐藏，录入后自动出现。
- **后台体积**：Element Plus 全量引入，产物 1.1 MB，仍待按需引入。
