## 4. 本轮修复的问题

1. **演示数据脚本调用了错误的发布方法**：内容发布是 `POST /api/admin/contents/{id}/publish`，脚本误用 `PUT`，返回 405。已改为 POST。
2. **案例缺少正文导致发布失败**：案例种子只写了摘要，发布校验要求 `bodyHtml`。脚本按摘要生成正文，并补 `industry`。
3. **分类重复**：早期脚本重复创建「数据采集」分类（id=1、2 未发布）。已通过后台接口删除，脚本改为按「类型+名称」复用已发布分类。
4. **素材记录与文件不一致**：素材表被清空但文件仍在磁盘，内容引用的 `coverMediaId=1` 失效。重新上传既有 PNG 后恢复，媒体 ID 回到 1。
5. **首页引用旧内容 ID**：案例/客户/服务分组仍指向已删除内容，公开聚合按规则整块过滤。回填新 ID 后首页六个区块全部恢复。
